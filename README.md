# 식탁 탐험가

개인 활동용 선택형 학습 보드게임입니다. 설치나 빌드 없이 동작합니다.

## 게임 구성

- 전개 1: 잔반 기록·식품군·미사용 재료·관찰 사실
- 전개 2: 시간·돌봄·구매 환경·조건 변화·원인 가설
- 전개 3: 질문·모의 인터뷰·사실과 추측·가설 검토
- 전개 4: 핵심 문제·수행 강점·생활 조화·다음 조사

각 단계는 4칸, 각 칸은 선택형 질문 1개입니다. 미션을 클리어하면 토큰을 얻고 다음 칸으로 이동합니다. 4칸을 완주하면 열쇠를 얻고 다음 보드가 열립니다. 오답은 감점 없이 재도전합니다. 의견형 질문에는 정답을 두지 않습니다.

자료는 수업용 가상 가족 예시입니다. 이름 입력은 선택입니다. 선택 내용은 브라우저 localStorage에 저장되며 서버로 전송되지 않습니다. 새 탐험을 누르면 이 버전의 저장 기록을 삭제합니다. 기존 웹앱의 진행 기록은 자동 이관되지 않습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 **내용 전체**를 저장소 루트에 올립니다. `index.html`이 저장소 최상위에 있어야 합니다.
3. 간단한 방법: Settings → Pages → Build and deployment → Source에서 **Deploy from a branch**, Branch에서 **main / (root)**를 선택하고 저장합니다.
4. 자동 워크플로를 사용할 경우 `.github/workflows/pages.yml`도 올리고, Source를 **GitHub Actions**로 선택합니다. main에 커밋하거나 Actions에서 워크플로를 수동 실행합니다.
5. 배포가 끝나면 Settings → Pages에서 사이트 주소를 확인합니다.

GitHub 웹 업로드에서 숨김 폴더가 누락되었다면 3번 방식으로 배포해도 됩니다. 공개 저장소의 Pages 사이트는 학생에게 URL로 공유할 수 있습니다. 저장소와 Pages 사용 가능 여부는 GitHub 계정 요금제·조직 정책을 따릅니다.

공식 안내: https://docs.github.com/ko/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 로컬 실행

`index.html`을 브라우저로 열거나 이 폴더에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000 으로 접속합니다.

## 수정할 파일

- index.html: 화면 구조와 메인 일러스트
- style.css: 색상·보드·게임 말·반응형 화면
- app.js: 선택 질문·정답·진행·SVG 일러스트·결과 인쇄

일러스트는 생성한 구아슈·종이 콜라주 이미지이며 assets/quest-illustrations.png에 포함되어 있습니다. 외부 이미지 호출이나 이모지 이미지는 사용하지 않습니다. 다음 차시 입장권은 선택한 조사 내용이 들어가는 탑승권 형식으로 화면과 인쇄물에 표시됩니다. 바코드는 장식이며 스캔 기능은 없습니다. 모바일 화면, 키보드 초점, 모션 감소 설정을 지원합니다.

## 확인 범위

16개 미션의 선택·빈 답변 방지·오답 재도전·단계 잠금·토큰 중복 방지·최종 결과 생성 로직을 검사했습니다. 실제 브라우저 화면과 GitHub 배포 실행은 별도 확인이 필요합니다.

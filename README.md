# 처음 만나는 우리 가족 식탁

개인용 서술형 학습 보드게임 전체 코드입니다. 첨부 레퍼런스의 크림색·초록색 큰 제목·책 장식·원형 미션 칸·연결 경로를 반영했습니다.

## 파일
- index.html: HTML·CSS·JavaScript 전체 코드. 이 파일 하나만으로 실행됩니다.
- .github/workflows/pages.yml: 선택적으로 사용할 GitHub Pages 자동 배포 설정
- verify.cjs: Node.js로 실행하는 주요 로직 검사 (`node verify.cjs`)

## 활동
전개 1 데이터 지도 / 전개 2 생활 조건 / 전개 3 인터뷰 / 전개 4 문제와 나의 역할.
각 전개 4칸, 각 미션에는 서술형 질문 1개와 짧은 자료가 있습니다. 학생이 답을 직접 작성하고 완료 버튼을 누르면 다음 칸이 열립니다. 네 칸을 완료하면 다음 단계가 열립니다.

자동 채점은 하지 않습니다. 빈 답안만 막고, 내용의 타당성은 자기 점검과 교사의 피드백으로 확인합니다. 자료는 가상 가족 예시이며 실제 가족 공개를 요구하지 않습니다.

이름 입력은 선택입니다. 답안은 localStorage에 저장되며 서버로 전송되지 않습니다. 이전 선택형 버전의 답안은 이관되지 않습니다. 다음 차시 탑승권에는 핵심 문제와 찾을 정보·출처·역할이 자동 반영됩니다. 바코드는 장식용입니다.

## 실행
index.html을 브라우저에서 엽니다. 설치와 빌드가 필요하지 않습니다.

## GitHub Pages 배포
1. 저장소를 만들고 이 압축 파일을 풉니다.
2. 폴더 자체가 아니라 폴더 안의 파일을 저장소 최상위에 올립니다. index.html이 루트에 있어야 합니다.
3. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
4. 자동 워크플로를 사용하려면 .github/workflows/pages.yml도 올리고 Source를 GitHub Actions로 선택합니다.

외부 이미지·외부 폰트·라이브러리 없이 작동합니다. 저장소 이름이 달라져도 추가 경로 수정이 필요하지 않습니다.

## 확인 범위
16개 미션의 서술형 입력, 빈 답안 완료 방지, 단계 잠금, 중복 보상 방지, 탑승권의 텍스트 이스케이프, 인쇄 생성, 저장 기록 재로드를 검사했습니다. 실제 브라우저 시각 검증과 GitHub 배포 실행은 별도 확인이 필요합니다.

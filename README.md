# 우리 가족 식생활 탐구 — 중3 미션 로드

중학교 3학년 개인 학습용 4단계 보드게임입니다. 연노랑 배경, 초록색 굽은 도로, 번호 표지판과 흰 설명 카드로 구성했습니다. 완료 스탬프는 첨부된 크레용 비행기 그림입니다.

## 구성
- 전개 1: 식생활 데이터 지도 (4미션)
- 전개 2: 가족의 생활 조건 (4미션)
- 전개 3: 인터뷰로 원인 확인 (4미션)
- 전개 4: 핵심 문제와 나의 역할 (4미션)

각 미션은 **선택형 2문항 + 서술형 1문항**입니다.
선택형은 정답과 설명을 확인하며 재도전합니다. 개인 의견을 묻는 문항에는 정답이 없습니다. 서술형은 비어 있는지 확인하며 내용의 타당성은 자동 채점하지 않습니다.

완료하면 비행기 스탬프를 받습니다. 완료 창에는 보드로 돌아가는 버튼만 있습니다. 다음 미션으로 자동 이동하지 않습니다. 보드에서 열린 칸을 직접 클릭합니다. 완료한 칸도 다시 열어 답안을 수정할 수 있습니다. 네 미션을 완료하면 다음 보드가 열립니다.

다음 차시 탑승권은 핵심 문제와 조사 계획을 자동으로 담고, 전체 답안과 함께 인쇄할 수 있습니다. 바코드는 장식용입니다.

## 중3 수준의 문항 설계
잔반량과 잔반율 비교, 식품군과 섭취량 구분, 미사용·식후 잔반 구분, 함께 변하는 조건의 영향, 시간·돌봄·구매 환경의 관계, 대안의 효과와 한계, 중립적 인터뷰, 사실·진술·원인 해석의 구분, 서로 다른 근거를 연결한 문제 정의를 다룹니다. 서술형은 자료 해석과 근거를 포함한 설명을 요구합니다.

## 전체 코드
`index.html`에 HTML, CSS, JavaScript, 비행기 이미지가 모두 들어 있습니다. 별도 이미지 다운로드, 외부 라이브러리, 빌드가 필요하지 않습니다. 비행기 그림은 이번 대화에 첨부된 사용자 제공 이미지를 내장했습니다.

질문 수정: `missions`는 자료와 서술형 질문, `choices`는 선택형 질문입니다. `correct`는 0부터 시작하는 정답 번호입니다. `null`이면 정답 없는 개인 의견형입니다.

## 실행과 배포
`index.html`을 브라우저에서 열어 실행합니다.

GitHub Pages:
1. 압축을 풀고 파일들을 저장소 최상위에 올립니다. `index.html`이 루트에 있어야 합니다.
2. Settings → Pages → Source: Deploy from a branch → main / (root)를 선택합니다.
3. 자동 배포를 원하면 `.github/workflows/pages.yml`을 포함하고 Source를 GitHub Actions로 설정합니다.

학생 답안은 해당 브라우저 localStorage에만 저장됩니다. 이름은 선택이며, 자료는 가상 가족 예시입니다. 이전 버전의 진행 기록은 자동 이관되지 않습니다.

## 검증
Node.js가 있다면 `node verify.cjs`로 주요 로직을 검사할 수 있습니다.
16개 미션의 문항 수, 선택형 판정, 서술형 필수 입력, 단계 잠금, 수동 미션 이동, 스탬프 중복 방지, 결과 출력의 안전한 텍스트 처리를 검사했습니다. 실제 브라우저 화면과 GitHub 배포 실행은 별도 확인이 필요합니다.
